# 🗺️ Roadmap

A versão atual representa o **MVP funcional** do projeto.

O projeto foi pensado para continuar evoluindo após esta primeira versão.

## Etapa 1 — MVP

- [x] Perfil profissional;
- [x] Cadastro de vagas;
- [x] Utilização do perfil salvo;
- [x] Importação de currículo por texto;
- [x] Interpretação de currículo com IA;
- [x] Análise de compatibilidade;
- [x] Match da vaga;
- [x] Identificação de lacunas;
- [x] Sugestões de melhoria;
- [x] Geração de currículo personalizado;
- [x] Edição do currículo;
- [x] Exportação em PDF;
- [x] Histórico de vagas e currículos.

## Etapa 2 — Personalização e qualidade

- [ ] Múltiplos modelos de currículo;
- [ ] Versionamento avançado;
- [ ] Personalização visual;
- [ ] Análise avançada da qualidade do currículo;
- [ ] Biblioteca de currículos.

## Etapa 3 — Desenvolvimento profissional

- [ ] Mapeamento consolidado de lacunas de competências;
- [ ] Plano de estudos personalizado;
- [ ] Sugestões de projetos para desenvolvimento profissional;
- [ ] Acompanhamento da evolução das competências;
- [ ] Currículos em diferentes idiomas;
- [ ] Análise de vagas em diferentes idiomas.

## Etapa 4 — Automação e integrações

- [ ] Importação de vagas por URL;
- [ ] Integrações com plataformas de emprego;
- [ ] Notificações e lembretes;
- [ ] Relatórios avançados;
- [ ] Automação do acompanhamento de candidaturas.
